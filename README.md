# Data-Analytics-Road-Accidental-Report-project-7

🚗 Road Accident Analysis Dashboard (Power BI Project)
An interactive Power BI dashboard analyzing road accident data across the UK — covering accident severity, vehicle types, road conditions, casualty trends, and location mapping. Built with dynamic KPIs and visualizations to support data-driven road safety strategies.

📉 Road Accident Analysis Overview
This project provides a comprehensive analysis of UK road accident statistics. The dashboard is designed to uncover key patterns in accident occurrences, severity levels, and contributing factors. It helps users understand when, where, and how road accidents are most likely to happen.

🎯 Business Objective
To conduct an in-depth analysis of:
- Total casualties and accident breakdowns  
- Accident severity: fatal, serious, and slight  
- Vehicle types involved in accidents (Car, Bike, Bus, Van, etc.)  
- Road types and their risk levels (single carriageway, roundabouts, etc.)  
- Urban vs Rural accident distribution  
- Day vs Night trends  
- Location heatmap across the UK  
- Year-over-year monthly trends  

🧰 Tools & Technologies Used
- Power BI – Dashboard design, data modeling, DAX measures  
- DAX – Custom calculations for KPIs and insights  
- Power Query – Data cleaning and transformation  
- Excel/CSV – Assumed source data format

📈 Dashboard Insights

- Cars: 155K+ | Bikes: 15.6K | Vans: 15.9K

2️ Urban vs Rural Area Accidents 
- Urban: 61.95% | Rural: 38.05%  

3️ Time of Day Analysis 
- Day Accidents: 73.84% | Night: 26.16%

4️ Casualties by Road Type
- Single carriageway: 145K  
- Dual carriageway: 32K  
- Roundabouts & slip roads: 13K and below  

5️ Monthly Casualty Trend (CY vs PY) 
- Consistent decrease in 2022 compared to 2021

This Power BI dashboard project delivers meaningful insights into road accident patterns, severity, and locations across the UK. It enables policymakers, safety analysts, and transport authorities to make informed decisions aimed at reducing road accidents and improving public safety.
